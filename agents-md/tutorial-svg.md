# 教程 SVG 插图规范

> 适用范围：`src/data/books/**/*.svg`（SVG → PNG 工作流的源文件）。
> 配套文档：frontmatter、书籍目录、图片引用规则见 `agents-md/writing.md`；Markdown 排版见 `agents-md/tutorial-markdown.md`。

## 核心原则

- **一致性优先。** 同一本书的所有插图应该像出自同一人之手——颜色、圆角、透明度、字号保持统一。
- **暗色主题优先。** 所有插图按深色背景设计，亮色主题下也能正常显示。
- **属性内联，不用 `<style>`。** 把 font-size、fill、stroke 等写在每个元素上，不要用 CSS class。Markdown 渲染时 `<style>` 块容易被拆散。
- **不要用 `currentColor`、CSS `var()`、`style` 属性。** PNG 转换后无法继承页面颜色。
- **这是静态教程插图规范。** 默认只用基础图元（`rect`、`line`、`path`、`text`、`g`）；不要引入动画或复杂 Web SVG 特性，除非这一张图确实非用不可。

默认不要使用这些特性：

- `<animate>`、`<animateTransform>`、`<animateMotion>`
- `<filter>`、`<pattern>`、`<mask>`、`<clipPath>`、`<foreignObject>`

允许但应谨慎使用的特性：

- `<defs>` + `linearGradient`：只在需要轻微层次感时使用，且必须是**同一语义色的透明度渐变**，不要做多色炫技。

## 调色板

### 语义色（高亮、标记、区分）

| 用途     | 颜色       | 说明                     |
| -------- | ---------- | ------------------------ |
| 蓝色     | `#3b82f6`  | 数据流向、寄存器、主要高亮 |
| 浅蓝     | `#60a5fa`  | 蓝色的次级变体           |
| 绿色     | `#10b981`  | 正确/成功/匹配           |
| 浅绿     | `#34d399`  | 绿色的次级变体           |
| 黄色     | `#fbbf24`  | 注意/警告/特殊标记       |
| 橙黄     | `#f59e0b`  | 黄色的次级变体           |
| 红色     | `#ef4444`  | 错误/溢出/危险           |
| 浅红     | `#f87171`  | 红色的次级变体           |

选择规则：

- 需要区分多种类别时，按 **蓝 → 绿 → 黄 → 红** 的顺序分配。
- 只需要一种高亮色时，优先用蓝色或绿色。
- 不要引入调色板之外的颜色（如橙色 `#ea580c`、紫色 `#8b5cf6` 等）。

### 中性色（文字、边框、背景）

| 用途     | 颜色       | 说明                     |
| -------- | ---------- | ------------------------ |
| 主文字   | `#94a3b8`  | slate-400，正文、标签、透明背景上的说明字 |
| 深灰文字 | `#475569`  | slate-600，浅色容器内的标题、强调文字 |
| 辅助灰   | `#64748b`  | slate-500，次要边框       |
| 深色块   | `#1e293b`  | slate-800，实心背景块     |

中性色使用规则：

- 直接放在透明背景上的标题、说明、结论，优先用 `#94a3b8`。它在深色主题下更稳，不容易发闷。
- `#475569` 不要作为透明背景上的裸字默认色；它更适合放在浅色容器、白底卡片或其他被底色托住的区域里。
- 如果一段关键信息必须同时兼顾深浅主题，优先考虑用容器承托，而不是硬找一个两边都完美的裸字颜色。

## 透明度

| 属性           | 范围      | 常用值               | 说明                         |
| -------------- | --------- | -------------------- | ---------------------------- |
| fill-opacity   | 0.04–0.08 | `0.05`, `0.08`       | 色块背景填充，保持淡雅       |
| stroke-opacity | 0.15–0.5  | `0.2`, `0.3`, `0.5`  | 边框、分割线、连接线         |
| opacity        | 0.4–0.8   | `0.6`, `0.8`         | 次要文字、注释、辅助标记     |

规则：

- 高亮色块的 fill-opacity 用 `0.05` 或 `0.08`，stroke-opacity 用 `0.3` 或 `0.5`。
- 未变化/未高亮的元素 stroke-opacity 用 `0.2` 或 `0.3`。
- 注释性文字 opacity 用 `0.6`。

## 圆角

| 属性 | 值  | 说明                   |
| ---- | --- | ---------------------- |
| rx   | `4` | 默认圆角，色块、按钮等 |
| rx   | `6` | 大容器、外层框         |

规则：

- 默认所有 `<rect>` 用 `rx="4"`。
- 大容器、整块外框允许用 `rx="6"`，同一张图里不要混入更多圆角尺寸。
- 不要用 `rx="3"`，也不要随意引入 `8`、`10` 之类更大的圆角。

## 字体

| 属性         | 值            | 说明                   |
| ------------ | ------------- | ---------------------- |
| font-family  | `sans-serif`  | SVG 根元素上设置一次    |
| font-size    | `14`          | 正文默认               |
| font-size    | `11`–`13`     | 注释、标签、次要文字   |
| font-size    | `15`–`16`     | 标题、重点数值         |
| font-size    | `10`          | 最小的辅助标记         |

规则：

- SVG 根元素写 `font-family="'Noto Sans SC','Microsoft YaHei','PingFang SC','Hiragino Sans GB',sans-serif"`，这是 WSL 环境下确保中文正确渲染的字体回退列表。
- 代码/地址/数值用 `font-family="monospace"`。
- 字号从小到大：10（最小标记）→ 11（标签）→ 12（注释）→ 13（小标题）→ 14（正文）→ 15–16（标题）。
- 中文使用微软雅黑（转换时通过 Resvg 的 `font.fontFiles` 指定 `/usr/share/fonts/truetype/windows/msyh.ttc`）。

## stroke-width

| 值   | 用途                     |
| ---- | ------------------------ |
| `1`  | 分割线、网格线           |
| `1.5`| 色块边框、元素边框       |

## 布局与分组

- 用 `<g>` 把同一块内容分组，再用 `transform="translate(...)"` 定位，不要让每个子元素都背一份大坐标。
- 同一行、同一列、同一模块内的元素，优先共享一个父 `<g>`，这样后续改尺寸或挪位置时只改一处。
- 能用基础图元就不用复杂 `path`。矩形、分隔线、说明块优先用 `rect` 和 `line`，保持可读、可改。
- 文字尽量保留为 `<text>`，不要转成路径；教程图后续经常改文案，保留文本最省事。

## 标题

每张 SVG 必须有且仅有一个标题行，放在内容区最顶部，让读者一眼就知道这张图在讲什么。

### 格式

```xml
<text x="20" y="30" font-size="16" font-weight="bold" fill="#94a3b8">标题文字</text>
```

### 规则

- **位置**：`x="20" y="30"`，内容区第一个元素，后续 `<g>` 从 `y=55` 开始（留出标题高度）。
- **字号**：`font-size="16"`。
- **颜色**：`fill="#94a3b8"`（透明背景统一用中性灰）。
- **粗细**：`font-weight="bold"`。
- **不写 `font-family`**：继承根元素的字体回退链。
- **内容风格**：
  - 优先写"指令名 + 做了什么"，如 `add 指令执行状态变化（无符号进位）`、`lea 指令执行过程详解`。
  - 需要区分同一指令不同场景时，括号补充，如 `（有符号溢出）`、`（借位场景）`、`（归零场景）`。
  - 多个图描述同一流程的不同阶段时，标题要能互相区分，不要三张图都叫 `movsx 扩展过程`。
  - 标题控制在 20 字以内，超了就精简或拆图。
- **不要用中文圆括号 `（）`**，统一用半角 `()`。

## 文本对齐

- 左对齐正文、注释、说明：默认不写 `text-anchor`。
- 居中数值、寄存器值、标签：用 `text-anchor="middle"`。
- 右上角补充说明、标题右侧状态栏：用 `text-anchor="end"`。
- 除非确实遇到垂直居中难题，一般不要引入 `dominant-baseline`；本项目现有图稿主要靠手动 `y` 值对齐。

## 渐变

- 默认不用渐变，纯色 + 透明度已经足够。
- 只有在大信息块需要轻微层次时，才允许用 `<defs>` + `linearGradient`。
- 渐变必须使用同一语义色，例如绿色从较高透明度过渡到较低透明度；不要在一个块里混蓝到绿、黄到红这类多色渐变。
- 渐变只是辅助层次，主信息仍然靠文字、边框、布局表达。

## viewBox 与尺寸

- viewBox 宽度通常 `840` 或 `960`，高度按实际内容 + `20px` 底部留白。
- **不要留过多底部空白。** 先确定内容最低点，再加 20px padding 作为 viewBox 高度。
- 根元素写 `width="100%" height="100%"`。

## SVG 结构模板

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 960 400" width="100%" height="100%" font-family="'Noto Sans SC','Microsoft YaHei','PingFang SC','Hiragino Sans GB',sans-serif" font-size="14">

  <!-- 标题（必须有） -->
  <text x="20" y="30" font-size="16" font-weight="bold" fill="#94a3b8">标题文字</text>

  <!-- 内容组 -->
  <g transform="translate(20, 55)">
    <!-- 高亮色块 -->
    <rect x="0" y="0" width="130" height="32" rx="4"
          fill="#3b82f6" fill-opacity="0.08"
          stroke="#3b82f6" stroke-opacity="0.3" stroke-width="1.5"/>
    <text x="65" y="22" font-family="monospace" font-size="14" font-weight="bold"
          text-anchor="middle" fill="#3b82f6">数值</text>

    <!-- 非高亮色块 -->
    <rect x="150" y="0" width="130" height="32" rx="4"
          fill="none" stroke="#94a3b8" stroke-opacity="0.3" stroke-width="1.5"/>
    <text x="215" y="22" font-family="monospace" font-size="14" font-weight="600"
          text-anchor="middle" fill="#94a3b8" opacity="0.7">数值</text>

    <!-- 注释文字 -->
    <text x="300" y="22" font-size="11" fill="#94a3b8" opacity="0.6">注释</text>
  </g>
</svg>
```

## 文件命名

- SVG 和 PNG 放在章节对应的 `*-images/` 目录下。
- 文件名用小写短横线：`mov-trace.svg`、`shl-cf-of-trace.svg`。
- 同一组 SVG/PNG 同名不同后缀。

## 转换命令

```bash
# 单个文件
npm run svg2png -- path/to/foo.svg

# 整个目录（递归查找所有 .svg）
npm run svg2png -- path/to/chapter-images/

# 多个路径
npm run svg2png -- a.svg b.svg some-dir/
```

## 检查清单

画完 SVG 后，按以下标准检查：

- [ ] 有且仅有一个标题行（`font-size="16"` `font-weight="bold"` `fill="#94a3b8"`），位于 `x="20" y="30"`
- [ ] 所有颜色都在调色板内（蓝/绿/黄/红 + 中性灰）
- [ ] 圆角只用 `rx="4"` 或容器级 `rx="6"`，没有 `3`、`8`、`10`
- [ ] 没有 `<style>` 块，所有样式内联
- [ ] 没有 `currentColor`、`var()`、`style` 属性
- [ ] 没有动画和复杂 Web SVG 特性；若用了 `<defs>` / `linearGradient`，确认只是同色透明度渐变
- [ ] 根元素 `font-family` 包含完整的中文回退列表
- [ ] viewBox 高度 = 内容最低点 + 20px，没有多余底部空白
- [ ] fill-opacity 在 0.04–0.08 范围
- [ ] stroke-opacity 在 0.15–0.5 范围
- [ ] 透明背景上的说明字优先用 `#94a3b8`，没有把 `#475569` 当成默认裸字色
- [ ] 相关元素已用 `<g>` 分组，坐标不是散落一地
- [ ] 文本仍是 `<text>`，不是转路径的死字
- [ ] 同名 PNG 已重新生成
